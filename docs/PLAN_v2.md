## 2. 売買の流れ（月1回）

| 日 | システム | ユーザー |
|---|---|---|
| 月の最終営業日 P の 17:30 以降 | データ取得 → 再学習 → 予測 → **売却リスト**（バッファで売る保有銘柄）と、**新しく買う銘柄**（点数の順、空き枠の数） | 売り注文（かぶミニの寄付取引。100株以上の部分は通常の寄付の成行）を、P の夜〜翌朝 8:45 に入れる |
| 翌月の第1営業日 S | 17:30 以降：売りの約定を反映し、**買い注文（1段目）の株数**を S の終値と現金で計算（`sell_to_first_buy_bdays` = 2 なら S の翌営業日に） | 9:05〜9:30 頃に売りの約定を確認・記録。夜（17:00〜翌8:45）に買い注文（1段目） |
| 第2営業日 B | 17:30 以降：**買い増し（2段目）の株数**を計算（案B） | 1段目の約定を記録。夜に買い増しの注文 |
| 第3営業日 B+1 | — | 2段目の約定を記録 |
| 売れなかった銘柄 | 次の営業日の夜に、もう一度売りのリストに載せる | 売り注文を入れ直す |

- 同じ寄付の売りの代金では買えない（寄付取引の受付は 17:00〜8:45 で、注文の時点で余力を拘束するため。E0 (4)）。**第1営業日にまとめる案は取れない**
- 新しく買う銘柄は P で決め、S・B の夜には変えない（買えなかった枠に、代わりの銘柄を買わない。v1 と同じ）

## 3. 細部の決め方（指示に無い細部。理由とともに DECISIONS.md に記録した）

### 3.1 期間
- 予測日 = 各暦月の最終営業日。評価の予測日は **2018-09-28〜2025-07-31 の83回**（2025-08-29 の予測は、売りが 2025-10-01（ホールドアウト）になるため使わない）
- 総資産の推移は予測日の引けで区切る（P_0 = 2018-09-28 〜 P_83 = 2025-08-29 の83か月）。最後の保有は 2025-08-29 の終値で評価し、売らない
- 前半 = 2018〜2021、後半 = 2022〜2025（期間の終わりの予測日の暦年）

### 3.2 目的変数と Rank IC
- 学習の目的変数：起点 t の **2営業日後の始値 → 22営業日後の始値** のリターン（調整後）の、t のユニバース内の順位（0〜1、同順位は平均）。
  2営業日後に始値が無い起点の行は使わない。22営業日後に始値が無ければ、その前の営業日までの最後の終値（調整後、上場廃止なら最後の終値）。
  実際の売買（第2営業日の寄付 → 翌々月の第1営業日の寄付）の長さは月によって18〜22営業日で、20営業日はその代表値
- 起点は v1 と同じく**すべての営業日**（目的変数の期間は重なる。月末だけにすると学習の行が約20分の1になるため）
- 調整係数の除外（案A）：目的変数の期間に判定の対象の係数の日（起点の3〜22営業日後）がある行は使わない
- 学習と評価の空白：予測日 P のモデルの学習に使う起点は **P の23営業日前まで**（目的変数の終わり（起点の22営業日後の始値）が P の前の営業日の朝までに確定する。
  起点と P の間に22営業日の空白）
- 月ごとの Rank IC：予測日の点数と、実際の売買の期間のリターン（P の2営業日後 B の始値 → 翌々月の第1営業日の始値。始値が無ければ前の営業日までの最後の終値）の、
  P のユニバース内の順位相関。B に始値が無い銘柄は除く。83か月は重ならないので、t値 = 平均 ÷ 標準偏差 × √83

### 3.3 長い期間の特徴量（2個。結果を見る前に決めた）
- `ret_220_20d`：t−220 営業日の終値 → t−20 営業日の終値の上昇率（調整後。直近1か月を除いた約10か月のモメンタム）。t−220 に上場していなければ欠損
- `dist_high_220d`：t の終値 ÷ 過去220営業日（t を含む）の高値（調整後）の最大 − 1。t−219 に上場していなければ欠損
- 選んだ理由：月次の保有で知られた効果（中期のモメンタム、52週高値からの距離）で、J-Quants Light の株価だけで作れる。v1 の `ret_60d`・`dist_high_60d` の長い版
- 長さ：Light（5年前まで）で、4年の学習期間の最初の行まで計算できる長さ。予測日の5年前〜4年前の営業日数は最小240（E0）。240営業日では余裕が0のため220にした（余裕20営業日）
- 学習の開始（2017-01-01）〜2017-09 頃の行では、データの開始（2016-10-05）から220営業日に満たないため欠損になる（リッジは0.5で埋める、LightGBM は欠損のまま。v1 の前年同期比と同じ扱い）

### 3.4 保有と売買（第5章の案）
- バッファの「上位20%」：P のユニバース内で点数の高い順（同点は銘柄コードの順）に1から順位を付け、**順位 ≤ ユニバースの銘柄数 × 0.2** なら上位20%
- 新しく買う銘柄は、持っていない銘柄（売れ残りも除く）を点数の高い順に。飛ばす銘柄：1株の拘束の単価が目標の金額を超える、目標の金額が20日平均売買代金の1%を超える
- 株数は S（第1営業日）の引け後に、S の終値と S の売りの後の現金で決める（注文を入れる時点で分かる情報）
- **約定しない**：始値が無い、**ストップ高の値段で寄った（その日にストップ高のフラグがあり、始値 = 高値）**、その日の朝に分割・併合が効く。
  売りは、始値が無い、**ストップ安の値段で寄った（ストップ安のフラグがあり、始値 = 安値）**、分割・併合が効く日は売れず、次の営業日の寄付に持ち越す。
  理由：かぶミニの寄付取引は 9:30 までに値が付かないと失効し、日足では寄った時刻が分からない。値幅の限度で寄った銘柄は、特別気配の後に寄ったことが多いため、保守的に約定しないとする
- 1注文は1〜99株：100株以上の株数は、100株単位の部分を通常の寄付の成行、端数をかぶミニで出す（どちらも寄付で約定。バックテストでは区別しない）
- 保有中の分割・併合：株数を直す（株数 ÷ 調整係数）。保有中に上場廃止：最後に銘柄一覧に載っていた日までの最後の終値で売ったとする（v1 と同じ）
- **本番だけの決まり**（バックテストには入れない。CLAUDE_v2_draft.md 第5章「本番とバックテストの差」。2026-10-05 決定）
  - 予測日の取扱一覧（ユーザーがスーパースクリーナーで出力）に無い銘柄は、新しく買う銘柄に選ばず、次の順位へ。参考の計算は同じ決まりで、今の一覧（2026-10-05）を全期間に当てる（未来の情報を含む）
  - 週1回、保有銘柄だけについて J-Quants の銘柄一覧の貸借信用区分を確かめ、「その他」（監理・整理銘柄など）になったら月の途中でも売る（次の営業日のかぶミニの寄付取引。売れなければ買取請求。楽天証券に確認中）。
    スクリプトはフェーズ v2-1 で作る

### 3.5 100株の比較（v1 の方法）
- 同じ月次・N=20・バッファ・同じ点数で、口座の方法だけを変える：買いは第2営業日の**寄付指値**（指値 = S の終値 × 1.02 を呼値で切り下げ、始値 < 指値で約定）、100株単位、
  売りは第1営業日の寄付の成行（通常の注文）。予算 = 総資産 × 0.97 ÷ N。コスト込みの注文の合計が現金を超える銘柄は飛ばす（v1 と同じ）。1段階
- コスト：一律0.3%と銘柄ごと（max(0.3%, 1呼値 ÷ 約定価格)）
- 50万円・N=20 では、100株を買えるのはユニバースの約7%（E0 (2)）。参考として出すだけで、合格の判定には使わない

## 4. モデルの決め方
- 主はリッジ回帰（v1 と同じ：特徴量を日ごとのユニバース内の順位に直し、欠損は0.5、alpha = 1.0）
- 比較は LightGBM の回帰（v1 と同じ固定のパラメータ）
- **決め方**：月ごとの Rank IC の差（LightGBM − リッジ、83か月）の t値が **2以上** なら LightGBM、それ以外はリッジ。**ポートフォリオの成績では決めない**
- 先に EXP-103（リッジで目的変数を並べ替え）で情報漏れが無いことを確かめる

## 5. 合格基準（第9章に登録する案）
判定は資金50万円で、売買コストは **0%と0.22%の両方** で満たす。データ費用の割合 = 19,800円 ÷ 50万円 = **年3.96%**。

| | 基準 |
|---|---|
| A | 月ごとの Rank IC の平均がプラスで、t値2以上（83か月） |
| B | モデルの確定の時点で、点数の上位20%（毎月等金額、コストなし）の**年率の超過リターン（上位20%の年率 − ユニバース平均（保有の窓）の年率）がデータ費用の割合（3.96%）以上**、かつ、**月ごとの超過リターンが0より大きいことの t値が2以上**。満たさなければ、**売買ルール（EXP-104 と合格の判定）に進まずに止め、同じ検証期間での再設計はせずに研究を終える** |
| C | 売買コストとデータ費用をすべて引いた年率がプラスで、ユニバース平均（月末の窓、コストなし）の年率も上回る |
| D | 過半数の年で、売買コストを引いた超過リターンがプラス |
| E | ランダム1,000回（同じ売買ルール・同じコスト）の年率の超過リターンの95%点以上 |
| F | モメンタム・リバーサル（同じ売買ルール・同じコスト）を上回る |
| G | 売買コストとデータ費用を引いた年率が、TOPIX を買って持ち続けた場合（配当なし、コストなし）の年率を上回る |
| H | ホールドアウト（12か月）で、**月ごとの Rank IC の平均がプラス**、かつ、**点数の上位20%のコストなしの年率の超過リターンがプラス**。N=20 のコスト後の成績は報告するが、合否に使わない |
| I | ペーパートレード（6〜12か月）は**執行の確認**（成績は合否に使わない）：(1) 期間の平均で、上位20銘柄のうちかぶミニで買えた割合が75%以上（下回ったら他社の単元未満株やユニバースの変更を検討）、(2) 約定価格と東証の始値の差は**ペーパートレードでは測れない**ので「通常、東証の寄付価格」を仮定し、コスト0.22%の側で見る（実測は v2-5 の最初の少額の運用）、(3) 約定しなかった割合、(4) 手順どおりに毎月できたか |
| J | 試行回数は v1 の4回から通算で数え、10回を超えたら止める |

- 年ごとの成績と、前半（2018〜2021）・後半（2022〜2025）の成績も併記する
- **ユニバース平均は2つ**（2026-10-06）：**月末の窓**（P_k の引け → P_{k+1} の引け、約定の判定なし）は N=20・ランダム・モメンタム・リバーサルの超過と基準 C・D・E に、
  **保有の窓**（B の寄付 → S' の寄付、約定の判定あり）は上位20%（基準 B・H）・5分位に使う。総資産の月次リターンの窓と比べる相手の窓をそろえるため（評価役の指摘）
- Standard のままの場合（年39,600円、7.92%）の基準 B・C・G の値も併記する（判定は Light の3.96%）
- 上位20%の年率の超過リターン = 上位20%の年率 − ユニバース平均（保有の窓、コストなし）の年率。上位20%の年率は83か月の（1 + 上位20%の月のリターン）の積から、N=20 と同じ年率の式・同じ年数で計算する。
  上位20%の超過の定義はこの1つだけで、基準B・7.4ポイントの決まり・基準 H で使う（2026-10-05 決定。「年の超過リターンの平均」は採らない。複利の年率のほうが保守的で、7.4ポイントの決まりと同じ定義で済むため）
- E0 (3) の目安：N=20 の年率の平均の標準誤差は約3.7%。**年7%未満の効きは、N=20 の成績では偶然と見分けられない**。E を満たすには、ランダムの平均より年率で約6%高い必要がある見込み
- **N=20 の年率の超過が、上位20%の年率の超過を 7.4ポイント（標準誤差の2倍）以上上回ったら、幸運か情報漏れを疑い、見込みの値には上位20%の超過を使う**（2026-10-05 決定）。
  この差は、基準のユニバース平均の窓が違う（月末の窓と保有の窓）分のずれを含む
- 標準誤差 3.7% は銘柄（と月）が独立という前提の下限で、バッファで同じ銘柄を持ち続ける v2 では実際のぶれはこれより大きい

## 8. 懸念点と、ユーザーの判断が要る点

### 8.1 かぶミニで買える銘柄の割合（E0 (1)：55.2% < 60%）→ E0b で測り直した（2026-10-05）
- 2025-09-26 のユニバースの55.2%（2024-12-17 時点の一覧。一覧の日のユニバースでは67.2%）。時価総額50億円未満で11%、200〜500億円で77%と、小さい銘柄ほど少ない

- 選択肢：(1) 最新の一覧（スーパースクリーナー）をユーザーが出力して測り直す、(2) ユニバースを時価総額100億円以上などに寄せる（100億円以上で67.6%（2025-09-26）・79.9%（2024-12-17））、
  (3) 一覧で絞った計算を主にする（未来の情報が入るので勧めない）、(4) 取扱いの広い他社の単元未満株を調べる
- 私の意見：まず (1) で今の割合を確かめ、それでも6割前後なら (2) を検討するのがよいと考える。(2) はユニバースの変更で、v1 の結果を見た後の変更になる点に注意（試行回数には数えないが、ホールドアウトの重みが増す）
- **E0b の結果（`reports/v2_e0b.md`）**：ユーザーが出力した今の取扱一覧（2026-10-05、2,074社）で、2025-09-26 のユニバースの **56.1%**（ほぼ変わらず）。
  ただし v1 の EXP-002 の点数の上位は、直近12か月の平均で **上位20銘柄の88.3%、上位20%の85.1%** が今の一覧にある（同じ日のユニバースは61.7%）
- **ユーザーの判断（2026-10-05）**：本番では予測日の取扱一覧に無い銘柄を飛ばして次の順位を買う。参考の計算も同じ決まりで、一覧は今の一覧に替える。
  基準 I は「上位20銘柄のうち買えた割合」とした（値とユニバースは下の 8.4 で決まった）

### 8.2 買付余力の拘束（E0 (4)）→ 案B を承認（2026-10-05）

### 8.3 そのほかの懸念
- **v1 の検証期間を使い回している**：v2 の設計は v1 の結果（売買コストが大きい、上位を買えない、下がる銘柄を避ける効きが強い）を見た後の変更。検証期間の成績は割り引いて見る必要があり、ホールドアウトとペーパートレードが重要
- **偶然のぶれが大きい**：N=20 でも1年の超過リターンの標準偏差は約10%（E0 (3)）。ペーパートレード6〜12か月での基準 I の後半（標準誤差の2倍）は、かなり大きな差しか検出できない
- **ホールドアウトが短い**：2025-09-29 以降の約12か月 → 月次では約12回。Rank IC・成績とも不確かさが大きい
- **バッファで「下がる銘柄を避ける」効きは使えるが、上位の差は小さかった**（v1）。月次・20銘柄でも、上位20%の超過がデータ費用（3.96%）を超えるかは分からない（基準B で早めに止める）
- **かぶミニの約定の価格**：公式に「通常、東証寄付価格」とあるが、異なる場合の記載もある。0.22%の成績で影響を見る
- **上場廃止・取扱停止**：かぶミニで売れなくなった単元未満株は買取請求（1件330円、約2週間）。整理銘柄は上場廃止日の2週間前をめどに売りが止まる。月1回の判断では間に合わないことがある。
  **本番の運用の決まりとしてだけ採用（2026-10-05）**：週1回、保有銘柄の貸借信用区分が「その他」になっていないかを J-Quants の銘柄一覧で確かめ、なっていれば月の途中でも売る（かぶミニで売れなければ買取請求。楽天証券に確認中）。
  バックテストには入れない（v1 と同じ「最後の終値で売れた」で、やや楽観的）。CLAUDE_v2_draft.md 第5章・第6章に「バックテストとの差」として書いた
- **0.97 の根拠**：指示の値。2段階の買いでは、拘束の単価が寄付の価格以上なので現金がマイナスにならず、0.97 は残す現金の目安として働く
- **データの更新時刻**：株価は16:30頃、翌営業日の銘柄一覧は17:30頃（J-Quants）。S・B の夜の株数の計算は 17:30 以降に行う
