2. **資金の目減りの連鎖**：予算 = min(30万円, 総資産) ÷ N のため、負けが続くと予算が縮み、50円台の超低位株しか買えなくなる（モメンタムは総資産が約1.4万円まで減り、注文の順位の平均が105位）。戦略どうしの比較が経路に左右されるため、比較用に「毎週の予算を30万円÷Nに固定した場合」の成績も併記することを提案する
3. スモークテストの結果：ユニバース平均（コストなし）は年率約−2%、モメンタムは Rank IC −0.031（t=−5.0）、リバーサルは +0.039（t=7.2）だが上位3銘柄はコストなしでも負け（IC は主に「大きく上がった銘柄が下がる」側から来ている）
