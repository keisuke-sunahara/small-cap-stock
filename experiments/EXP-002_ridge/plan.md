# EXP-002：線形モデル（リッジ回帰）

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-002`／共通の決まり：`experiments/README.md`
試行回数：数える

## 仮説
CLAUDE.md 第7章の「比較用の線形モデル」。特徴量の順位を線形に組み合わせるだけでも、LightGBM と同程度の予測ができるなら、
単純なモデルの方が過学習のおそれが小さい。LightGBM が線形モデルを明確に上回らなければ、非線形の組み合わせの効果は小さいと考える。

## 変更内容
- `model.type: ridge`：日ごとにユニバース内の順位（0〜1）に直した特徴量（欠損は0.5で埋める）で、目的変数の順位をリッジ回帰（alpha = 1.0）で予測する
- それ以外（学習期間、目的変数、売買ルール）は EXP-001 と同じ

## 判断基準
- README 第4章のモデルの確定の手順で、EXP-001・004 と同じ基準で比べる（EXP-005 は参考で、採用候補にしない）
- 採用候補が複数あるときは、単純な順（リッジ回帰 EXP-002 → LightGBM の回帰 EXP-001 → LightGBM の lambdarank EXP-004）に並べ、より複雑なモデルは、それより単純なすべての採用候補に対する週次リターンの差（予算固定・一律0.3%）の t値が2以上の場合だけ選ぶ（README 第4章。2026-10-05 実行の前に追加）
