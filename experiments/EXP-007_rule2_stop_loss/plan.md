# EXP-007：候補2：損切り（−8%の逆指値）

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-007`／共通の決まり：`experiments/README.md`
試行回数：数える

変更の記録：2026-10-05、評価役のフェーズ4計画の指摘（中1）を受けて約定の計算を直した（実験は1つも実行していない時点。ユーザーの指示）。
以前は「場中に触れたら逆指値の価格で売る」としていた

## 仮説
大きく下がった銘柄を早めに売ると、1週間の大きな損失を抑えられ、最大ドローダウンが小さくなる。成績が上がるかは分からない（売った後の戻りを逃すため）。

## 変更内容（CLAUDE.md 第5章の候補2）
- 買いが約定した日から、逆指値の価格 = 買値 × (1 − 0.08) を呼値の単位で切り下げた価格で売り注文を入れる（ユーザーは買いの約定後に入れる。第6章）
- 毎営業日、日足で判定する：始値 ≤ 逆指値の価格なら始値で売る（窓を開けて下回った）。そうでなく安値 ≤ 逆指値の価格なら、
  **逆指値の価格 − 1呼値**（逆指値の価格の帯の呼値）で売る（逆指値の成行は、触れた価格より下で約定することが多いため）。
  買った日は、始値（買値）より後の値動きなので、安値だけで判定する
- 当たった日にストップ安のフラグがあり、終値が安値と同じ（張り付いた）場合は、その日は売れず、次に売買が成立した日の始値で売る
  （引成の売りの判定と同じ扱い。窓を開けた場合も同じ）
- コストは約定価格で計算する（銘柄ごとのコストは、窓を開けた場合は始値、場中に触れた場合は 逆指値の価格 − 1呼値、張り付いた場合は後日の始値）
- 始値が無い日（売買不成立・ストップ安で寄らない）は売れず、次の営業日に同じ判定をする
- 継続保有中も、最初の買値をもとにした逆指値の価格を使う（分割・併合があれば調整係数で直す）
- 損切りで売った後、その週の残りは現金のまま（代わりの銘柄は買わない）。翌週以降は、他の銘柄と同じく選ばれれば買う
- 最終営業日に損切りの条件に当たった場合も、損切りで売ったものとする（日足では時刻が分からないため。前場に当たれば実際も損切りで売れる。
  後場に当たった場合、ユーザーは11:30〜に損切りを取り消して引成を入れているので本来は引成で売れるが、保守的に損切りとする）
- コストは他の売買と同じ（片道0.3%、または銘柄ごと）。権利付最終売買日をまたぐ逆指値の失効（第6章）は、入れ直したものとする

## 判断基準
- 採用の判断は上の計算（窓を開けたら始値、触れたら 逆指値の価格 − 1呼値、張り付いたら後日の始値）で行う
- 参考として「触れた日の安値で売れた」場合（窓を開けた場合も含め、当たった日の安値で売る。張り付いた日の扱いは同じ）も出す。判断には使わない
- 点数：モデルの確定（README 第4章）で決めた実験の点数をそのまま使う（`logs/backtest/<その実験ID>/scores.parquet`）
- 比べる相手：同じ点数 ＋ 基本ルール。採用の条件は README 第5章（一律0.3%と銘柄ごとのコストの両方で予算固定の年率の超過リターンが上回る、週次の差の t値 ≥ 2.0（2026-10-05 に1.0から変更。実行の前）、最大ドローダウンの悪化が5ポイント未満）

## リスク
- 日足では、触れた後の約定価格は分からない。逆指値の価格 − 1呼値 は、急落の途中で当たった場合には有利な仮定になりうる（参考の安値の計算と並べて見る）。
  逆に、安値がちょうど逆指値の価格だった日は、実際には安値より下では売れないので不利な仮定になる
- 報告すること：損切りに当たった件数、窓を開けた件数と割合、ストップ安に張り付いてその日に売れなかった件数、売った価格とその日の終値の差、
  張り付いた銘柄を後日の始値で売った価格と逆指値の価格の差
