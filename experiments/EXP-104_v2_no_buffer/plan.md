# EXP-104：バッファなし（毎月、上位20銘柄に入れ替える。参考）

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-104`／共通の決まり：`experiments/README_v2.md`
試行回数：数える（v1 からの通算で7回目。採用候補にしないが、同じ検証期間で成績を出すため）

> 状態：**実行しない（評価役の確認とユーザーの承認の前）**。ユーザーの判断（2段階の買い（案B）、合格基準 B・H・I の変更、ユニバースは変えない、基準 I-1 は75%以上、基準B は上位20%の年率の超過）は 2026-10-05 に反映済み

## 目的
バッファ（上位20%から落ちるまで持ち続ける）が、入れ替えの回数とコストをどれだけ減らし、成績にどう効いたかを見るための参考。
**採用候補にしない**（バッファの値・N の比較はしない、と事前に決めているため。結果がバッファありより良くても、売買ルールは変えない）。

## 実行の条件
- モデルの確定と基準B の後に実行する（README_v2 第1章の順番）。基準B で止まった場合は実行しない
- 点数は確定したモデルの実験（EXP-101 か EXP-102）のものを使う。確定したら config.yaml の `model_experiment` に書いてコミット・送信してから実行する

## 変更内容
- `buffer.keep_top_fraction: null`：予測日ごとに、保有銘柄も含めて点数の順に上位 N（=20）銘柄を選び直す。
  保有銘柄は「新しく買う銘柄の判定」（1株の拘束の単価が目標の金額以下、目標の金額が平均売買代金の1%以下）なしで数え、持っていない銘柄は判定を満たすものだけを数える（v1 の継続保有の数え方と同じ）。
  上位 N に入った保有銘柄は売らずに持ち続け（売って買い直さない）、入らなかった保有銘柄を売り、空いた枠に上位 N の残りの銘柄を買う。売れ残りは保有として数えない
- それ以外（点数、売買の日、株数、2段階の買い、コスト）はバッファありと同じ

## 出すもの（判断はしない）
- バッファありとの比較：年率・年率の超過リターン（0%・0.22%）、回転（年あたり）、平均の保有月数、月次リターンの差の t値
