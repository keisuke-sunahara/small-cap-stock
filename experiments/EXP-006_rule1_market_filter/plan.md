# EXP-006：候補1：地合いフィルター

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-006`／共通の決まり：`experiments/README.md`
試行回数：数える

## 仮説
TOPIX が20日移動平均を下回る下げ相場では、小型株も全体に下がりやすく、買わずに現金で待つ方が損失を減らせる。

## 変更内容（CLAUDE.md 第5章の候補1）
- 予測日 p の TOPIX の終値が、p を含む過去20営業日の終値の平均を下回っていたら、翌週は新しく買わない
- 「現金で待つ」ため、継続の判断の日 c（最終営業日の前の営業日）にも同じ判定をし、下回っていたら保有銘柄を継続せずに、その週の最終営業日の引けですべて売る
  （c の時点で分かる情報だけで判断する。最終営業日の引けの TOPIX を見てから引けで売ることはできないため）
- 注文リストには、買わない週の理由を書く（第6章）

## 判断基準
- 点数：モデルの確定（README 第4章）で決めた実験の点数をそのまま使う（`logs/backtest/<その実験ID>/scores.parquet`）
- 比べる相手：同じ点数 ＋ 基本ルール。採用の条件は README 第5章（一律0.3%と銘柄ごとのコストの両方で予算固定の年率の超過リターンが上回る、週次の差の t値 ≥ 1.0、最大ドローダウンの悪化が5ポイント未満）

## リスク
- 移動平均のフィルターは、急落の後の戻りを取り逃しやすい。年ごと・相場環境ごとの成績も見る
