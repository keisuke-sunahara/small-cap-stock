# EXP-004：LightGBM（lambdarank：順位付けの学習）

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-004`／共通の決まり：`experiments/README.md`
試行回数：数える

## 仮説
売買に使うのは上位の数銘柄だけなので、全体の二乗誤差（回帰）より、上位の並びを重視する順位付けの学習（lambdarank）の方が、
上位の銘柄の選び方が良くなる（PLAN.md 6.3 で比較を予定していたもの）。

## 変更内容
- `model.objective: lambdarank`：起点の日ごとを1つのグループとし、目的変数（順位）を10分位の整数（0〜9）に直したものをラベルにする。
  評価は NDCG、`lambdarank_truncation_level: 30`。それ以外のパラメータ・期間・売買は EXP-001 と同じ

## 判断基準
- README 第4章のモデルの確定の手順で、EXP-001・002 と同じ基準で比べる（EXP-005 は参考で、採用候補にしない）
- 採用候補が複数あるときは、単純な順（リッジ回帰 EXP-002 → LightGBM の回帰 EXP-001 → LightGBM の lambdarank EXP-004）に並べ、より複雑なモデルは、それより単純なすべての採用候補に対する週次リターンの差（予算固定・一律0.3%）の t値が2以上の場合だけ選ぶ（README 第4章。2026-10-05 実行の前に追加）

## リスク
- 上位を重視する学習は、上位の当たり外れの偶然にも合わせやすい（過学習）。回帰との差が小さければ、単純な回帰を優先する理由になる
