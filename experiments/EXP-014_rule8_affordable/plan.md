# EXP-014：候補8：買える銘柄だけで学習・順位付け

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-014`／共通の決まり：`experiments/README.md`
試行回数：数える

## 仮説
基本の方法は全銘柄で学習するが、30万円・N=3 で100株を買えるのは株価約1,000円以下の銘柄だけ。予測上位が買えない銘柄に偏ると、実際に買うのは順位の低い銘柄になる。
買える銘柄だけで学習・順位付けすると、買える銘柄の中での並びが良くなる。

## 変更内容（CLAUDE.md 第5章の候補8）
- 「買える」：起点の日 t の終値から計算した指値（終値 × 1.02 を呼値で切り下げ）で、100株の金額が 30万円 ÷ N 以下（予算固定の基準）
- 学習：特徴量の順位と目的変数の順位を、日ごとに「ユニバース ∩ 買える」の銘柄の中で計算し、その行だけで学習する
- 点数：ユニバースの全銘柄に点数を付ける。特徴量は「ユニバース ∩ 買える」の銘柄の分布の中での位置（順位）に直す（買えない銘柄にも点数が付くので、
  基本ルールどおり、継続保有の判断で値上がりして買えなくなった保有銘柄も順位に入る）
- モデルの種類・パラメータは、確定したモデルと同じ。**モデルを学習し直すので、点数を `logs/backtest/EXP-014/scores.parquet` に保存する**
- 売買ルールは基本ルールと同じ

## 判断基準
- 比べる相手：確定したモデル ＋ 基本ルール。採用の条件は README 第5章（一律0.3%と銘柄ごとのコストの両方で予算固定の年率の超過リターンが上回る、週次の差の t値 ≥ 1.0、最大ドローダウンの悪化が5ポイント未満）
- あわせて、Rank IC（「ユニバース ∩ 買える」の中で計算したもの）を、確定したモデルと並べて報告する
