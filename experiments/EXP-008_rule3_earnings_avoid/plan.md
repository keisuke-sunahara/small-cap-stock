# EXP-008：候補3：決算の回避

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-008`／共通の決まり：`experiments/README.md`
試行回数：数える

## 仮説
決算の発表で株価は大きく動く。保有期間中に決算発表がある銘柄を避けると、予測できない大きな値動きを減らせる。

## 変更内容（CLAUDE.md 第5章の候補3）
- 予測日 p：翌週の保有期間（最初の営業日〜最終営業日の暦日）に、p までに公表された決算発表予定日がある銘柄を、順位付けの対象から除く
- 継続の判断の日 c：継続すると保有が続く期間（その週の最終営業日〜翌週の最終営業日の暦日。最終営業日の引け後の発表は翌週の寄付に効くため、
  最終営業日を含める）に予定日がある保有銘柄は継続せずに売る。保有していない銘柄も、この期間に予定日があれば「上位N」の数から除く
- 予定日は、公表日の次の営業日の引け後から使う（CLAUDE.md 第5章）。同じ四半期の最新の公表が「未定」なら、その四半期の予定日は不明
- **予定日が「未定」の銘柄の扱い（評価役の指摘・低2、ユーザーの指示で事前に決める）**：
  - 案A（採用）：「未定」の銘柄も除く。「未定」の状態 = その銘柄の最新の予定日の記録が「未定」で、その記録を使えるようになってから決算短信がまだ出ていない
  - 案B：除かない（予定日が分かっている銘柄だけを除く）
  - 案A を選ぶ理由：候補3の目的は、保有期間中の決算発表の値動きを避けることで、「未定」は決算発表の時期が近いのに日付が決まらない状態（2020年のコロナ禍の延期、
    監査の遅れなど）であることが多く、むしろ大きく動く可能性が高い。保守的に除く
  - 影響の大きさ（リターンは見ていない）：予測日のユニバースで「未定」の状態の銘柄は合計658行、予測日あたり平均1.8銘柄（2020年が245行）。どちらの案でも成績への影響は小さい見込み
- 予定日がまだ公表されていない銘柄（決算の直後の約1か月など）は除かない（予定日が7日以内に迫ってから公表される例は1.5%）

## 判断基準
- 点数：モデルの確定（README 第4章）で決めた実験の点数をそのまま使う（`logs/backtest/<その実験ID>/scores.parquet`）
- 比べる相手：同じ点数 ＋ 基本ルール。採用の条件は README 第5章（一律0.3%と銘柄ごとのコストの両方で予算固定の年率の超過リターンが上回る、週次の差の t値 ≥ 1.0、最大ドローダウンの悪化が5ポイント未満）

## リスク
- 決算の発表の後には、上振れ・下振れの続きの動き（決算後のドリフト）があり、モデルがそれを使っている場合は、避けると成績が下がる
