## 2. 共通の条件

- **期間**：評価の予測日は 2018-09-28〜2025-07-31（83回）。総資産の推移は 2018-09-28 の引け〜2025-08-29 の引け（83か月）。ホールドアウト（2025-09-29 以降）は使わない
- **売買**：CLAUDE_v2_draft.md 第5章の基本の売買ルール（月次、売りは第1営業日の寄付、買いは第2営業日の寄付（2段目は第3営業日）、N=20、目標の金額 = 総資産 × 0.97 ÷ N、
  1株単位、バッファ上位20%、注文金額 ≤ 20日平均売買代金の1%）。資金50万円
- **コスト**：かぶミニは0%（主）と片道0.22%。100株の比較は一律0.3%と銘柄ごと
- **ウォークフォワード**：予測日ごとに学習し直す。学習の起点は予測日の23営業日前まで（22営業日の空白）、直近4年のローリング、2017-01-01以降
- **目的変数**：起点の2営業日後の始値 → 22営業日後の始値のリターンの、ユニバース内の順位（案A の係数の日（起点の3〜22営業日後）を含む行は使わない）
- **特徴量**：`all_v2`（v1 の16個 ＋ `ret_220_20d`・`dist_high_220d`）。日ごとにユニバース内の順位（0〜1）。欠損はリッジでは0.5、LightGBM ではそのまま
- **モデルの設定は固定**（`config/base.yaml` の `model.lightgbm`・`model.ridge`。v1 と同じ値）。結果を見てパラメータを調整しない
- **乱数**：LightGBM の seed 42、deterministic、スレッド4。目的変数の並べ替えは乱数シード42。ランダムのベースラインは乱数シード0〜999
- **ベースライン**：ランダム1,000回・モメンタム・リバーサル・ユニバース平均（月末の窓）・TOPIX を買って持ち続けた場合。同じ期間・同じ売買ルール・同じコストで、フェーズ v2-1 で計算して `reports/` に保存したものを使う
- **ユニバース平均は2つ**（2026-10-06。定義は CLAUDE_v2_draft.md 第5章「ベースライン」）
  - **ユニバース平均（月末の窓）**：P_k の引け → P_{k+1} の引け、P_k のユニバースの全銘柄を等金額（終値が無ければ直前の終値、上場廃止は最後の終値。約定の判定なし、毎月すべて入れ替え、コストなし）。
    戦略（N=20）・ランダム・モメンタム・リバーサルの超過リターン、基準 C・D・E、7.4ポイントの決まりの N=20 の側に使う
  - **ユニバース平均（保有の窓）**：B の寄付 → S' の寄付（約定の判定あり、約定しない銘柄は0%、売れなければ次の寄付、コストなし）。上位20%（基準 B・H）・予測の5分位に使う

### 3.1 合否に使わない指標（2026-10-06、評価役の確認による。すべての実験で出す）
- **9:30 の失効の感度**：約定とみなした売買（1段目・2段目・売り）のうち、始値が前の営業日の終値（調整後）から ±10% 以上離れた件数と、それらを約定しないとした場合の年率（コスト0%・0.22%）
- **1割の月の買いを見送った場合の年率**：83か月のうち8か月を乱数で選び、その月の新しい買い（1段目・2段目）をしない。乱数シード0〜99 の100通りの平均と最小（コスト0%・0.22%）
- **銘柄の集中**：月末の最大の銘柄比率（平均・最大）、比率が10%を超えた月数

### 3.2 ストレステスト（2026-10-06。合否には使わない。確定したモデルの実験の `results.md` に必ず書く。EXP-101・102 は両方で出す）

3. **寄付の後の不利な価格**：買い（1段目・2段目）は（始値 + 高値）÷ 2、売りは（始値 + 安値）÷ 2 で約定したとする（約定の判定は同じ。コスト0%・0.22%）

## 4. モデルの確定（EXP-101・102 の後）

1. EXP-103 で情報漏れが疑われないこと（EXP-103 の plan.md の基準）。疑われたら止めて報告する
2. 月ごとの Rank IC の差 d_m = （EXP-102 の Rank IC）−（EXP-101 の Rank IC）、m = 83か月。t値 = d の平均 ÷ d の標準偏差 × √83
3. **t値 ≥ 2 なら LightGBM（EXP-102）、それ以外はリッジ（EXP-101）**。ポートフォリオの成績（年率・超過リターンなど）では決めない
4. 確定したモデルが基準 A（Rank IC の平均がプラスで t値2以上）を満たさなければ、そのことを報告する（基準B の計算はする）

## 5. 基準B（モデルの確定の直後）

- 確定したモデルの、点数の上位20%（予測日ごとに等金額、コストなし、資金制約なし。保有の窓のリターン）について、年率の超過リターン（上位20%の年率 − ユニバース平均（保有の窓、コストなし）の年率）と、月ごとの超過リターン（ユニバース平均（保有の窓、コストなし）との差、83か月）を計算する（定義は CLAUDE_v2_draft.md 第5章「目的変数と評価」）
- **次の両方を満たさなければ、EXP-104 と合格の判定に進まずに止めて報告する**（「優位性は見つからなかった」。同じ検証期間での再設計はせず、研究を終える。第1章）
  1. 上位20%の年率の超過リターン ≥ データ費用の割合（19,800円 ÷ 50万円 = 3.96%）
  2. 月ごとの超過リターンが0より大きいことの t値（平均 ÷ 標準偏差 × √83）≥ 2
- 上回ったら、EXP-104 に進む。ここでは止まらない（結果は最後にまとめて報告する）

## 6. EXP-104 と合格の判定

- EXP-104（バッファなし）は参考で、採用候補にしない。確定したモデルの点数を使い、バッファだけを変える（毎月、上位20銘柄に入れ替える）
- 合格の判定は、**確定したモデル ＋ 基本の売買ルール（バッファあり）** で行う（CLAUDE_v2_draft.md 第9章の A〜G。H はホールドアウト（Rank IC と上位20%の超過）、I はペーパートレード（執行の確認）、J は試行回数）
- N=20 の年率の超過リターン（0%・0.22%。ユニバース平均（月末の窓）に対する）が、上位20%の年率の超過リターン（ユニバース平均（保有の窓）に対する）を 7.4ポイント以上上回ったら、幸運か情報漏れを疑って調べ、見込みの値には上位20%の超過を使う（CLAUDE_v2_draft.md 第9章）。
  この差は、基準にするユニバース平均の窓が違う分のずれを含む
- 合格なら、`release-v2` の候補として提案し、ホールドアウトの前に止まる。不合格なら、結果をそのまま報告する
