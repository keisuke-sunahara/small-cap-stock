# EXP-012：候補6：順位による傾斜配分（条件付き）

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-012`／共通の決まり：`experiments/README.md`
試行回数：実行すれば数える（事前の確認で傾向が無ければ実行せず、数えない）

## 事前の確認（CLAUDE.md 第5章の6と7に共通するルール）
実行する前に、予測上位の中で「順位が高いほど実際のリターンも高い傾向」があるかを、次の方法で確かめる（確定したモデルの点数を使う）。
- 各予測日に、基本ルールの選定と同じ条件（ユニバース、100株を買える、売買代金の1%以下）を満たす銘柄を点数の高い順に10銘柄並べ、
  翌週の実現リターン（最初の営業日の始値→最終営業日の終値。コストなし）と、順位（1〜10）との順位相関を計算する
- 364週の平均がマイナス（順位の数字が小さいほどリターンが高い）で、t値が −2 以下なら「傾向がある」とし、実行する。それ以外なら実行せず、確認の結果を報告する

## 仮説
上位ほどリターンが高いなら、上位により多く配分すると成績が上がる。

## 変更内容（CLAUDE.md 第5章の候補6）
- 予測日に、その週に持つ銘柄（継続保有 ＋ 新しく買う銘柄）を予測日の点数の高い順に並べ、k 位の銘柄に資金の w_k を配分する（w = 40%・35%・25%）
- 新しく買う銘柄の予算 = （予算固定なら30万円、基本ルールなら min(30万円, 総資産)）× w_k。継続保有の銘柄は株数を変えない
- 選定（どの銘柄を買うか）は基本ルールと同じ（均等の予算で100株を買えるか・売買代金の1%以下で判定）。そのあと、配分した予算で株数を決め直し、
  100株も買えなければその枠は現金のまま（他の銘柄に回さない）。売買代金の1%以下の上限も、決め直した株数で判定する
- 1銘柄に50%を超えて配分しない（40%なので該当しない）
