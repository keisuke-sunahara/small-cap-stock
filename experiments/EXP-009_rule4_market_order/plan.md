# EXP-009：候補4：指値なし（寄付の成行）

登録：2026-10-05（実行の前）／ブランチ：`exp/EXP-009`／共通の決まり：`experiments/README.md`
試行回数：数える

## 仮説
指値（前日の終値 + 2%）で買えなかった銘柄は、大きく上がって始まった銘柄。成行で必ず買う場合と比べて、指値の効果（高値づかみを避ける効果、または上がる銘柄を逃す損）を確かめる。

## 変更内容（CLAUDE.md 第5章の候補4）
- 買い：寄付の成行。始値があれば始値で約定する。始値が無い（ストップ高で寄らない・売買停止）場合は約定しない。始値がストップ高（ストップ高のフラグがあり、始値がその日の高値と同じ）なら、
  比例配分で買えないことがあるため、約定しないとする（保守的）
- 買う日の朝に分割・併合が効く銘柄は約定しないとする（指値と同じ。注文の株数が分割前の基準のため）
- 株数・選定・現金の判定は指値の場合と同じ（指値の価格で計算する。成行でも証券会社は値幅の上限で余力を拘束するため）。違いは約定の判定だけ

## 判断基準
- 点数：モデルの確定（README 第4章）で決めた実験の点数をそのまま使う（`logs/backtest/<その実験ID>/scores.parquet`）
- 比べる相手：同じ点数 ＋ 基本ルール。採用の条件は README 第5章（一律0.3%と銘柄ごとのコストの両方で予算固定の年率の超過リターンが上回る、週次の差の t値 ≥ 1.0、最大ドローダウンの悪化が5ポイント未満）

## 補足
- 指値なしの方が良くても、指値をやめるかは、大きく上がって始まる銘柄を買うコスト（板寄せで自分の注文が値を上げる）も考えて提案する
