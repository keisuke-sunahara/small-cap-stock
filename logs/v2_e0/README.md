`kabumini_yoritsuki_2026-10-05.csv` の形式
- 列：コード、銘柄名、市場。UTF-8（BOM 付き）。ユーザーが出力した元のファイルには 現在値・前日比(%) の列もあるが、写しには入れない
- コードは4文字（数字4桁、または `141A` のような英字入り）。J-Quants の5桁のコードとは、末尾に `0` を付けて照合する
- 「現在値」「前日比」は 2026-10-05 の値（ホールドアウトの期間）。分析では読まない。2026-10-05 の最初のコミット（eb76cb9）の写しには入っていたため、3列に置き換えた。
  git の履歴には元の列が残る（履歴は書き換えない。`docs/DECISIONS.md`）。元の5列のファイルは `data/external/` にだけ残す（コミットしない）

## 取扱一覧を読むときの決まり（2026-10-05 決定）
- ユーザーが毎月置く取扱一覧（`data/external/kabumini_yoritsuki_YYYY-MM-DD.csv`）も、**読み込みの時点で価格の列（現在値・前日比など）を捨て、コード・銘柄名・市場 の3列だけを使う**（`config/base_v2.yaml` の `production.kabumini_lineup_keep_columns`）
